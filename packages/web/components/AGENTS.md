# web/components/ — Feature UI Components

**Score ~18** (100 files, ~8.6k LOC; 72 `.tsx` + styles; feature-module component library).

## OVERVIEW

The React component library for the `web` package, organized by feature (no single barrel). Routes in [`../app`](../app/AGENTS.md) compose these. Includes the landing DAG/graph visualizations, docs shell, download experience, home/landing/manifesto/ledger/support sections, and the shadcn-style `ui/` primitives.

## STRUCTURE (>5 feature dirs)

| Dir | Role |
|-----|------|
| `docs/` | `DocsShell`, `DocsSidebar`, `useDocsNavigation`, `wrapTables` |
| `download/` | `DownloadExperience`, `InstallerList`, `PrimaryDownload`, `VerifyDownload`, `useDesktopVisitor` |
| `home/` | Home page + `sections/*`, `styles/*` (tokens/base/chrome/hero/sections/motion), theme + nav + reveal |
| `landing/` | `dag/` (DAG layout/scenario/motion, `computeDagLayout`, `useDagCamera`, `useDagPlayback`), `graph/` (`GraphHero`, `GraphScene`, palette/data) |
| `ledger/` | `BentoGrid`/`BentoCell`, `Frame`, `LedgerRow`, `Reel` |
| `manifesto/` | `ManifestoSection`, reading + section modules |
| `support/` | `SupportReportPanel` |
| `ui/` | shadcn-style `Badge`, `Button`, `Card*`, `Input`, `Separator`, `Section`, `Tooltip` |

## CONVENTIONS

- Feature modules export their own public symbols; there is no directory-wide barrel.
- Animation uses `IntersectionObserver` (not scroll listeners) and only `transform`/`opacity`. CSS/Tailwind animation, no `framer-motion` (narrow `motion/react` shared-layout exception).
- DAG layout/geometry concentrates in `landing/dag/layout.ts`; scenario and motion logic are separate (`scenario.ts`, `motion.ts`).
- Docs content under `components/docs/` is generated by `scripts/generate-docs-content.mjs` — edit source docs, not generated output.

## ANTI-PATTERNS

- Do not add `framer-motion`; avoid serif typography and layout-property animation (`width`/`height`/`top`/`left`/margin/padding).
- Do not edit generated docs output. The known 390×844 docs horizontal overflow is accepted debt — do not worsen it without docs-shell design work.
- Bun only (no `npm install`); Prettier enforced.

## COMMANDS

- From `packages/web/`: `bun run dev` · `bun run build` · `bun run type-check` · `bun run format:check`
